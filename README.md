# RUTINE - Advanced Habit Tracker

A premium, editorial-style habit tracking application with liquid glass aesthetics and advanced analytics.

## Features
- **Editorial Luxury Design**: A stunning, premium interface.
- **Advanced Analytics**: Track your progress with dynamic SVG charts and trends.
- **Firebase Integration**: Secure authentication and data persistence.
- **Responsive Layout**: Optimized for all devices.

## Setup
1. Clone the repository.
2. Run `npm install`.
3. Run `npm start` (or use a local server for `index.html`).
